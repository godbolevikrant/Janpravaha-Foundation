# Janpravaha Social Foundation Website

Responsive static website built with HTML5, CSS3, Bootstrap 5 and JavaScript.

## Main pages
- `index.html` — Home
- `about.html` — About Us
- `team.html` — Our Team
- `work.html` — Our Work
- `gallery.html` — Gallery
- `contact.html` — Contact

## Run locally
Open the folder in Visual Studio Code and launch `index.html` with Live Server, or open the file directly in a browser. Bootstrap and Bootstrap Icons are loaded from their CDNs, so an internet connection is recommended.

## Before publishing
Replace illustrative gallery photos with approved photos, add verified team names and roles, confirm official contact details, and connect forms to a backend/email service. The current forms are demonstration-only and do not store or send submissions.
